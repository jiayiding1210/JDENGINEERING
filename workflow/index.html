DIGITAL DESIGN TOOLS & WORKFLOWS

Jiayi develops lightweight design tools for focused engineering tasks and integrated workflows that connect established software platforms. The goal is to simplify repetitive work without losing the technical detail, traceability, and engineering judgment required for bridge and structural design.

SIMPLIFIED DESIGN TOOLS

These tools are intended to make common design calculations more efficient and transparent. Selected applications will be hosted directly on this site, with dedicated pages for the engineering assumptions, inputs, design checks, and outputs.

INTEGRATED DESIGN WORKFLOWS

Jiayi develops integrated workflows that move information efficiently between established analysis and design platforms, using each tool where it is strongest. The objective is a more seamless design process with less repetitive work, while maintaining technical detail and reviewability.
